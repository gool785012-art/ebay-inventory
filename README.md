# eBay在庫管理ツール（Web版）公開手順書

スマホ・PCなどどこからでもアクセスできるように、無料でネット上に公開する手順です。
アプリストアの審査や署名作業は一切不要です。

---

## できあがるもの

`https://（自動生成された名前）.vercel.app` のようなURLが発行されます。
このURLにアクセスすれば、スマホでもPCでもタブレットでも同じ画面が使えます。

**重要な注意点**: データはブラウザの`localStorage`に保存される設計のため、**「同じブラウザ」でアクセスしないとデータは共有されません**。例えばPCのChromeで入力したデータは、スマホのSafariには表示されません（別々の保存領域になります）。複数端末でデータそのものを共有したい場合は、後述の「データ共有について」を参照してください。

---

## 必要なもの

- GitHubアカウント（無料）
- Vercelアカウント（無料、GitHubアカウントでそのまま登録可能）

---

## 手順1：GitHubアカウントを作る（すでにあればスキップ）

1. https://github.com にアクセス
2. 「Sign up」から登録（メールアドレスとパスワードのみでOK）

---

## 手順2：コードをGitHubにアップロードする

### パターンA：Gitコマンドを使う場合（PowerShellで作業）

このフォルダ（`ebay-inventory-web`）の中で：

```bash
git init
git add .
git commit -m "初回コミット"
```

その後、GitHub上で新しいリポジトリを作成（「New repository」ボタン、Public/Privateどちらでも可）し、表示される指示に従って：

```bash
git remote add origin （GitHubが表示するURL）
git branch -M main
git push -u origin main
```

### パターンB：Gitを使わずブラウザだけで行う場合（簡単）

1. GitHubで「New repository」から新規リポジトリを作成
2. 「uploading an existing file」のリンクをクリック
3. `ebay-inventory-web`フォルダの中身（`node_modules`フォルダは**含めない**）をすべてドラッグ＆ドロップ
4. 「Commit changes」をクリック

---

## 手順3：Vercelで公開する

1. https://vercel.com にアクセスし、「Continue with GitHub」でログイン
2. 「Add New...」→「Project」をクリック
3. 先ほどアップロードしたリポジトリを選択し、「Import」
4. 設定はそのまま（Vercelが自動でVite構成を検出します。Build Command: `npm run build`、Output Directory: `dist`になっていることだけ確認）
5. 「Deploy」をクリック
6. 1〜2分待つと、URLが発行されて公開完了です

---

## 手順4：スマホで開いてホーム画面に追加する（任意）

発行されたURLをスマホのブラウザで開き、以下のようにするとアプリのアイコンのようにホーム画面に置けます。

**iPhone（Safari）の場合**: 共有ボタン（□に↑のアイコン）→「ホーム画面に追加」

**Android（Chrome）の場合**: 右上の「︙」メニュー→「ホーム画面に追加」または「アプリをインストール」

これでアイコンをタップするだけでブラウザのアドレスバーなしで全画面表示され、見た目はほぼネイティブアプリと同じになります（これを「PWA」と呼びます）。

---

## コードを修正した後の更新方法

GitHubにアップロードしたファイルを更新してプッシュ（またはブラウザで再アップロード）するだけで、Vercelが自動的に検知して再公開してくれます。手動の再デプロイ作業は不要です。

---

## データ共有についての補足

今の設計（localStorage）は「このブラウザだけ」にデータが保存される、最も手軽でシンプルな方式です。これは以下のような場合に向いています。

- 1人で、基本的に同じPC（またはスマホ1台）から使う
- 複数端末からは見るだけで、入力は1箇所に決めている

一方で、「PCで入力したデータをスマホでも見たい・編集したい」というニーズが出てきた場合は、データをどこかのサーバー（データベース）に保存する仕組みに変更する必要があります。これは設計が変わる比較的大きな変更になるので、その場合は改めてご相談ください。
