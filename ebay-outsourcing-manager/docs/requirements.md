# eBay外注管理ツール 要件定義書（原文）

発注者からの開発依頼内容を整理したものです。原文の要求を忠実に記録しています。

## 1. 開発目的

日本からeBayで海外販売（カメラ・レンズ・ゲーム機・オーディオ機器・ターンテーブル・腕時計・その他中古品）を行っており、外注スタッフに以下の業務を依頼する。これらを管理できる専用ツールを作成する。

- 商品受け取り / 商品確認 / 検品 / シリアル番号確認 / 写真撮影 / 梱包 / サイズ・重量測定 / 発送準備 / 発送 / 追跡番号登録 / 作業完了報告

GoogleスプレッドシートやLINEで分散している外注管理を1つのWebアプリにまとめる。PC・スマートフォン両対応のレスポンシブWebアプリ。

## 2. 技術構成

- フロントエンド: React / Next.js / TypeScript / Tailwind CSS
- バックエンド: Supabase（PostgreSQL / Supabase Auth / Supabase Storage）
- デプロイ: Vercel
- できるだけ無料枠または低コストで運用

## 3. ユーザー権限

### 管理者
すべてのデータを閲覧・編集可能。
商品登録・編集・削除、外注スタッフ登録、担当者割り当て、ステータス変更、写真確認、発送情報確認、報酬設定、報酬集計、コメント、作業履歴確認。

### 外注スタッフ
自分が担当している商品のみ表示。閲覧・編集項目は必要最低限。
担当商品確認、商品到着報告、検品結果入力、シリアル番号入力、写真アップロード、梱包完了報告、サイズ入力、重量入力、発送完了報告、追跡番号入力、コメント入力。

**販売価格・仕入価格・利益などの情報は外注スタッフには表示しない。**

## 4. ダッシュボード（管理者用）

本日の状況（未着 / 商品到着 / 検品待ち / 梱包待ち / 発送待ち / 発送済み）を件数カードで表示。カードクリックで該当商品一覧へ移動。
その他: 今月発送件数 / 今月外注費 / 外注スタッフ別作業件数 / 最近更新された商品 / 発送期限が近い商品。

## 5. 商品管理

必須項目: 管理番号（重複不可、例 CAM-0001 / GAME-0001 / AUDIO-0001 / WATCH-0001）、商品名、商品カテゴリー、商品画像、担当スタッフ、ステータス、商品到着日、発送期限、発送日、発送会社、追跡番号、重量、縦、横、高さ、備考。

## 6. 商品カテゴリー

初期カテゴリー: Camera / Lens / Game Console / Audio / Turntable / Watch / Other。管理者が追加・変更可能。

## 7. ステータス

未発送（仕入先）/ 外注先へ発送済み / 商品到着 / 検品中 / 検品完了 / 梱包中 / 梱包完了 / 発送待ち / 発送済み / 問題あり / 保留。
ステータスごとに分かりやすいバッジを表示。

## 8. 作業フロー（外注スタッフ）

1. **商品到着**: 到着日、外箱写真
2. **商品確認**: 商品本体写真、付属品写真、シリアル番号、シリアル写真
3. **検品**: 外観状態、動作確認、問題の有無、コメント
4. **梱包前確認**: 梱包前写真
5. **梱包**: 梱包途中写真、梱包完了写真
6. **サイズ測定**: 重量kg、縦cm、横cm、高さcm
7. **発送**: 発送会社、追跡番号、発送日、発送ラベル写真 → 完了ボタンでステータス「発送済み」

## 9. 写真管理

Supabase Storage使用。写真カテゴリー: 外箱 / 商品本体 / 付属品 / シリアル番号 / 梱包前 / 梱包途中 / 梱包完了 / 発送ラベル / その他。
スマホから直接撮影・アップロード、複数枚可、一覧表示と拡大表示。

## 10. 商品詳細ページ

上部: 商品画像・商品名・管理番号・担当者・ステータス。
中央: 作業進捗タイムライン（商品到着→検品→梱包→サイズ測定→発送）。
下部: 写真・コメント・発送情報・作業履歴。

## 11. コメント機能

商品ごとに管理者と外注スタッフがコメント可能。投稿日時と投稿者を表示。

## 12. 作業履歴

すべての変更履歴を保存（誰が・いつ・何を変更したか）。

## 13. 外注スタッフ管理

登録項目: 氏名 / メールアドレス / 電話番号 / 登録日 / ステータス（稼働中・休止・契約終了）/ 備考。

## 14. 報酬管理

商品カテゴリーごとの報酬設定（例: 小型商品500円、カメラ800円、レンズ800円、ゲーム機1,000円、大型オーディオ2,000円、ターンテーブル2,500円）。金額は管理者が自由に変更可能。商品単位でも報酬を上書き可能。

## 15. 月別報酬

外注スタッフごとに月別報酬を自動集計。CSV出力可能。

## 16. 検索

管理番号 / 商品名 / 追跡番号 / 担当スタッフ。

## 17. フィルター

ステータス / 担当スタッフ / 商品カテゴリー / 発送日 / 発送期限。

## 18. 発送会社

初期値: FedEx / DHL / Japan Post / UPS / Other。

## 19. 発送期限警告

3日以内=黄色、1日以内=オレンジ、期限超過=赤。

## 20. 商品登録方法

通常登録 + CSV一括登録。

## 21. QRコード

商品登録時に管理番号からQRコードを自動生成。外注スタッフがスマホで読み取ると商品詳細画面が開く。**非常に重要な機能。**

## 22. 外注スタッフ用トップページ

シンプルな画面。今日の作業（到着確認待ち / 検品待ち / 梱包待ち / 発送待ち）。「次にやる作業」がすぐ分かるUI。

## 23. マニュアル

アプリ内マニュアルページ。カテゴリー: 商品受け取り / 検品 / 写真撮影 / カメラ梱包 / レンズ梱包 / ゲーム機梱包 / オーディオ梱包 / ターンテーブル梱包 / 発送 / トラブル時対応。管理者が後から編集可能。

## 24. ターンテーブル梱包チェックリスト

以下すべてチェックしないと「梱包完了」にできない:
プラッター取り外し / プラッター個別固定 / カウンターウェイト取り外し / ヘッドシェル取り外し / トーンアーム固定 / ダストカバー保護 / 本体が箱内で動かない / 底面補強 / 角の保護 / 梱包前写真 / 梱包途中写真 / 梱包後写真。

## 25. 問題報告

外注スタッフが「問題あり」ボタンで問題内容・写真・コメントを登録。管理者ダッシュボードに警告表示。

## 26. 通知（将来）

LINE通知 / メール通知 / Discord通知。MVPでは実装不要だが追加できる構造に。

## 27. セキュリティ（非常に重要）

外注スタッフには eBayログイン情報 / パスワード / 仕入価格 / 販売価格 / 利益 / 不要な顧客情報 を絶対に表示しない。
Supabase Row Level Security を使用。外注スタッフは「自分に割り当てられた商品」だけアクセス可能。URL直接入力でも他スタッフの商品にはアクセス不可。

## 28. UIデザイン

Notion + Shopify管理画面 + 物流管理システムのようなUI。白ベース / 余白多め / スマホ対応 / 大きめボタン / 状態が一目で分かる / 操作方法を覚えなくても使える。外注スタッフはITに詳しくない前提。

## 29. データベース

最低限: users, staff, products, product_photos, product_comments, work_logs, shipping, payments, manuals, categories。可能であれば正規化。

## 30. 将来追加したい機能

eBay API連携 / eBay販売商品の自動取得 / FedEx API / DHL API / 送り状自動生成 / Commercial Invoice自動作成 / 在庫管理 / 仕入管理 / 利益管理 / バイヤー管理 / 返品管理 / 破損補償管理 / AI商品状態判定 / AI商品説明作成 / AI英語翻訳 / 写真から型番認識 / バーコード読み取り / スマホカメラで商品登録。

## 31. 開発順序

- Phase 1: プロジェクト構築 / Supabase接続 / ログイン / 権限 / DB設計
- Phase 2: 商品管理 / ステータス / 担当者割り当て / 商品詳細
- Phase 3: 外注作業画面 / チェックリスト / 写真アップロード
- Phase 4: 発送管理 / 追跡番号 / サイズ / 重量
- Phase 5: 報酬管理 / 月別集計
- Phase 6: QRコード / マニュアル / 作業履歴
- Phase 7: UI改善 / スマホ最適化

## 最重要事項

**「外注スタッフが迷わず作業できること」** を最優先。次に何をすればよいか分かる / 入力忘れがない / 写真を必ず残す / 発送ミス・梱包ミス・商品間違いを防ぐ / 作業履歴が残る。まず実運用できるMVPを完成させ、その後機能追加。
