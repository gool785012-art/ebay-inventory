# eBay外注管理ツール 作業スタッフ用 かんたんマニュアル

スマホでもパソコンでも使えます。画面の案内どおりに進めれば大丈夫です。

（配布用Word版はこの内容と同じです。URL・アカウント情報を記入してスタッフに渡してください）

## 1. ログインする

1. ツールのURLをブラウザ（SafariやChrome）で開く
2. メールアドレスとパスワードを入れて「ログイン」を押す

- URL：（管理者が記入）
- メールアドレス：（管理者が記入）
- パスワード：（管理者が記入）

💡 スマホの「ホーム画面に追加」をしておくと、次からアプリのようにワンタップで開けます。
（Safari：共有ボタン→ホーム画面に追加 ／ Chrome：メニュー⋮→ホーム画面に追加）

## 2. 毎日の使い方

ログインすると「今日の作業」が表示されます。商品名の横の「作業する →」を押すと、その商品の作業画面が開きます。

作業画面には STEP1〜7 が並んでいて、次にやる作業が自動で開き「← 次はこの作業です」と表示されます。上から順に、画面のとおり入力していくだけでOKです。

| STEP | 作業 | やること |
|---|---|---|
| 1 | 商品到着 | 商品が届いたら、外箱の写真を撮って「到着を報告する」を押す |
| 2 | 商品確認 | 商品本体・付属品・シリアル番号の写真を撮り、シリアル番号を入力 |
| 3 | 検品 | 外観の状態を書き、動作確認の「○」か「×」を押して保存 |
| 4 | 梱包前確認 | 梱包する前の状態の写真を撮る |
| 5 | 梱包 | 梱包途中と梱包完了の写真を撮り、「梱包完了を報告する」を押す |
| 6 | サイズ測定 | 梱包後の重さ（kg）と縦・横・高さ（cm）を測って入力 |
| 7 | 発送 | 発送会社・追跡番号・発送日を入れ、ラベルの写真を撮って「発送完了」 |

STEP7の「✓ 発送完了」を押したら、その商品の作業はすべて終わりです。おつかれさまでした！

## 3. 写真のポイント

- 「📷 写真を撮影 / 選択」ボタンを押すと、その場でカメラ撮影ができます（複数枚OK）
- 明るい場所で、傷や汚れがある部分は必ずアップで撮ってください
- 写真は多いほど安心です。迷ったら撮ってください

## 4. 商品に問題を見つけたら

傷・カビ・動作不良・付属品の不足・届いた箱の破損など、気になることがあったら作業を止めて報告してください。

1. 画面下の赤い「⚠ 問題を報告する」ボタンを押す
2. 問題の内容を書く（例：レンズ内にカビがあります）
3. 問題の箇所の写真を撮る
4. 「報告する」を押す → 管理者に伝わるので、返事を待ってから作業を再開

ちょっとした質問や連絡は、商品ページの下にある「コメント」に書いてください。管理者からの返事も同じ場所に表示されます。

## 5. ターンテーブル（レコードプレーヤー）の梱包

ターンテーブルは特に壊れやすい商品です。梱包のSTEPに専用のチェックリストが表示されるので、1つずつ実際に確認しながらチェックを入れてください。全部チェックしないと「梱包完了」は押せない仕組みになっています。

## 6. 困ったときは

| 症状 | 対処 |
|---|---|
| ログインできない | メールアドレスとパスワードの入力ミス（空白・大文字小文字）を確認。直らなければ管理者に連絡 |
| 担当の商品が表示されない | まだ担当の割り当てがない状態です。管理者に確認してください |
| 写真がアップロードできない | 電波の良い場所でもう一度お試しください。何度も失敗する場合は管理者に連絡 |
| 操作を間違えた・わからない | そのままで大丈夫です。商品ページのコメントか、いつもの連絡方法で管理者に聞いてください |

**わからないまま進めるより、聞いてもらう方が助かります。遠慮なく連絡してください。**
